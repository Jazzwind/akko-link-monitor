# 参考与许可

- [2.4G-battery-viewer 的 PROMPT.md](https://github.com/yszyszysz233/2.4G-battery-viewer/blob/main/PROMPT.md)：参考其数字托盘、Win32 生命周期、启动文件夹和 HID 并发注意事项。没有采用其中其他设备的私有协议；保留本项目诊断日志。
- [SteamMonitorTray](https://github.com/Jazzwind/SteamMonitorTray)：参考并移植其自启动状态处理和三档启动显示策略，Python 实现独立维护，不读取或修改 SteamMonitorTray 配置。
- AKKO 3098N 电量读取使用本项目验证的设备协议；官方安装包、固件和个人分析资料不随源码发布。
