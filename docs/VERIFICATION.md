# 验证与发布验收

## 自动验证

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\run-tests.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\check-release.ps1
```

默认测试不要求连接 AKKO，实机缓存／设备枚举两项跳过；增加 `-Hardware` 可运行本机检查。测试不会发送任意 HID 命令、刷固件或注入 Windows 按键。

已验证的类别包括：

- 配对、重复、扩展键、修饰键超时、上下文、断开／暂停／队列溢出时不伪造恢复，以及 BT1／2.4G 隔离。
- UI 与 CSV／JSON 写入、重新开始日志、电量来源分离、断开后只保留最后已知电量。
- 双击回调一次一标记、连续两次编号不同、暂停连续日志仍保存、写入失败显示 !、反馈结束恢复最新电量、窗口按钮与会话镜像使用相同编号。
- 原生图标创建与三次启停，关闭后线程／窗口均结束；StartupApproved 未知值不猜测为启用。
- 隔离快捷方式目录与测试注册表键验证重复注册、移除、任务管理器禁用保留、外部变更读取；不修改真实启动项或 SteamMonitorTray。
- 含空格／中文和不同用户式数据目录迁移，原设置和历史日志不删除。
- 通过临时 Git 仓库验证发布白名单；当前项目仓库不被初始化。

## 原生桌面验证

在没有生产版同名测试窗口的情况下，可执行：

```powershell
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
py -3 tests\desktop_checks.py
```

该脚本使用真实 Tk 窗口、原生托盘和 WinEvent 显示事件钩子，后台设备采集被替换为合成队列。测试只在 `verification/` 内创建隔离数据；不会改真实启动项。

验证三种隐藏策略在手动／自启动两种入口的六种组合。应隐藏的组合既检查最终不可见，也检查没有初始主窗口显示事件；同时检查重复自启动不显示、重复手动启动前置、X 隐藏、双击不弹窗口且写入标记、模拟 TaskbarCreated 重建通知，以及定时调用正常退出后无残留窗口。模拟重建通知不实际重启资源管理器。

最后一次实现验收：Windows 11、Python 3.13 64 位；54 项测试通过（默认跳过 2 项实机测试），上述 6 种显示组合通过。原始测试输出保留在本机忽略目录，不随发布附带。

## 需要真实登录确认的部分

快捷方式目标、参数和工作目录可以直接核对，不能完全替代真实登录验收。请在方便时自行注销／登录，确认托盘出现、窗口不显示、没有 UAC 和控制台、日志持续保存。自动验证不主动重启或注销。

新图标是否常显由 Windows 用户设置控制；首次可能需要从折叠区拖出。不同显示缩放和主题下的数字可读性仍建议实际检查。

2026-10-27 有线输入及表格修复：64 项测试中 62 项通过，2 项可选实机测试跳过。测试覆盖三档 Tk 字体缩放下行高足以容纳字体、四张表格双向滚动；有线 K／句号键重复与释放、其他键按下不伪造 K 已松开、拔除接收器不清除有线按住状态、有线不关联无线失联事件、不调用接收器电量接口，以及有线来源进入手动标记与日志。设备识别经过实机 Fn+6 前后只读枚举对照：新增六个 `320F:506A` HID 接口，产品名 `AKKO Multi-modes Keyboard-N`。旧日志未采集的有线事件无法追溯补齐。

手动刷新调整后的回归：61 项测试中 59 项通过，2 项可选实机测试跳过。合成请求验证闲置／自动查询关闭时显式刷新只查询一次，超时不自动重试、连续两次操作分别查询、不会延长活动窗口；UI 验证闲置结果可见、30 秒后失效、未知来源不因查询被判为 2.4G、BT1 只刷新缓存、单次超时不产生自动失联事件。

2026-10-27 休眠修复：58 项回归测试中 56 项通过、2 项可选实机测试跳过。新增合成时钟及输入测试验证：启动／闲置／手动关闭时不发送电量命令，超时重试与刷新不绕过 15 秒闲置门限，连续有输入时保留正常查询频率，重复按下事件不延长活动窗口，切换 BT1 停止查询，闲置结束失联观察时不伪造恢复，迟到的查询回复不覆盖暂停状态。测试使用独立数据目录和临时目录，不操作生产日志。用户实机对照已观察到关闭旧版主动查询后恢复熄灯；修复后的实机休眠时间仍需日常使用确认。

- 目录动作显式启动 Explorer，失败会提示且不会中断后续托盘命令处理。
- 长按阈值、拖出取消、双击与长按互斥、开始／结束区间和退出观察中断，使用合成事件验证。
- 合并日志测试包含同名不同内容、相同内容去重、复制失败保留原件、相同或嵌套根目录拒绝。生产导入只复制，不删除源文件；显式整理在逐文件核验后将原件另行改名归档，保留备份。
